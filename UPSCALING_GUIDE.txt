IMAGE UPSCALING GUIDE

SETUP COMPLETE ✓
---------------
- Virtual environment created: venv/
- Pillow installed and working
- Upscaling script ready: upscale_images.py

UPSCALING METHODS AVAILABLE
----------------------------
1. LANCZOS (Recommended) - Best quality for character images
   - Smooth, high-quality upscaling
   - Best for preserving character details
   - Slightly slower but worth it

2. BICUBIC - Good quality, smooth
   - Faster than Lanczos
   - Good for most cases

3. BILINEAR - Moderate quality
   - Faster
   - Acceptable for simple images

4. NEAREST - Fast but pixelated
   - Not recommended for character images
   - Creates blocky artifacts

HOW TO USE
----------

1. TEST MODE (Recommended first):
   Upscales only 5 images per directory to test:
   
   venv/bin/python upscale_images.py --size 64 --method lanczos --test
   
   This creates directories like: vowels/1_upscaled_64/

2. FULL UPSCALING (All images):
   Upscales all 221 images per directory:
   
   venv/bin/python upscale_images.py --size 64 --method lanczos
   
   This will process all 2,652 images (takes a few minutes)

3. UPSCALE TO 128x128:
   For higher resolution:
   
   venv/bin/python upscale_images.py --size 128 --method lanczos

4. COMPARE METHODS:
   See which method looks best:
   
   venv/bin/python upscale_images.py --compare --size 64
   
   Opens comparison images in: upscale_comparison/

OUTPUT STRUCTURE
----------------
Original: vowels/1/001_01.jpg (28x28)
Upscaled: vowels/1_upscaled_64/001_01.png (64x64)

- Images are saved as PNG (better quality than JPG)
- Original images are NOT modified
- New directories created with suffix: _upscaled_64 or _upscaled_128
