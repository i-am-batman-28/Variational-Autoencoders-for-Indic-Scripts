SLIDE TEXT:
• Indic scripts (e.g. Hindi/Devanagari, Telugu) have rich structural and stylistic complexity.
• Automated character generation and representation learning for these scripts is challenging.
• Conventional autoencoders learn compact representations but do not model the underlying probability distribution.
• Variational Autoencoders (VAEs) enable probabilistic latent space learning and controlled generation of character samples.
• This project focuses on designing VAEs for printed Indic script characters (Hindi and Telugu) and building a curated dataset for training and evaluation.

SLIDE 12 — DESIGN (VAE PIPELINE — PLANNED)
================================================================================
HEADLINE: Design — VAE Pipeline (Planned)

PHOTOS TO PUT:
  • One diagram: VAE architecture — Input (128×128) → Encoder (Conv layers) → μ, σ → Reparameterize (z) → Decoder (Transposed Conv) → Reconstruction. Draw in PPT or use a standard “VAE architecture” image from the web (e.g. from Kingma & Welling or a blog).
  • Optional: Small sample input image (e.g. dataset/akshar/a/14pt/a_14pt_01.png) on the left and a placeholder “Reconstruction / Generation” on the right to show input–output.

SLIDE TEXT:
• Input: 128×128 character image (normalized).
• Encoder: Convolutional layers → flatten → μ and log σ² (latent dimension d, e.g. 32–128).
• Reparameterization: z = μ + σ × ε, ε ~ N(0, I).
• Decoder: Dense → reshape → transposed convolutions → reconstruction (same size as input).
• Loss: L = reconstruction_loss (e.g. BCE or MSE) + β × KL(q(z|x) || p(z)); optional β-schedule.
• Training: Adam optimizer; batch size and epochs TBD; validation reconstruction and generation checks.
• Output: Reconstructed images; generated images via z ~ N(0, I); latent codes for visualization.
